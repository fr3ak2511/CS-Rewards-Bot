# Progression milestone and Grenade balance register

The fixed monthly Reward Chain reference contains these 25 thresholds:
3, 6, 12, 15, 18, 56, 59, 62, 65, 123, 126, 129, 141, 147, 186, 189, 192, 195, 400, 600, 680, 750, 880, 950, 1000.

The email and Copy Report show the complete ladder and a roster-complete per-account
balance register. Each row distinguishes the last actual balance, the minimum at
that observation date, the current date-based minimum, observation age, thresholds
reached by balance, and the next threshold from the reference ladder.

An older observation is not presented as a fresh current balance. Legacy validation
status that was never stored remains unknown; the report does not infer a PASS from
the count alone. A threshold reached by balance is not evidence that its reward
card was Delivered. Exact milestone delivery remains a separate portal-verification
requirement and is not populated by this balance register.
